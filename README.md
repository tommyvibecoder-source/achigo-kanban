# Tech Production Kanban — AI-First Startup PM Platform

An intuitive, collaborative Product Management and Kanban platform inspired by **Jira** and **Confluence**, built specifically for tech startup teams to document customer pain points in natural language, deliberate ideas with full team consensus gates, score opportunities, craft AI prompt directives, code with autonomous AI developers, perform manual QA testing, and ship to market.

---

## 7-Stage End-to-End Workflow

1. **Backlog / Ideation**: Capture customer friction and problem statements in plain natural language.
2. **Under Refinement**: Scoping, user stories, value proposition, and founder debate.
3. **Consensus Reached 🤝**: Unanimous 100% team approval lock before advancing.
4. **Prompt Creation ✍️**: Fine-tuning directives, constraints, and architecture guidelines tailored for **Google Antigravity**, **Claude Code**, or **Openwork**.
5. **In AI Production ⚡**: Autonomous coding by the AI dev team.
6. **Manual Testing & QA 🧪**: Hands-on verification checklist with test scenarios, expected outcomes, tester attribution, and Pass/Fail gates.
7. **Shipped to Market 🚀**: Live in production with verified customer value.

---

## Quickstart & Local Development

```bash
# 1. Install dependencies
npm install

# 2. Run automated tests
npm test

# 3. Start development server
npm run dev
```

Visit **`http://localhost:5173`** in your browser.
